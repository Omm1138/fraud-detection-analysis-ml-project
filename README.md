# 🔍 Fraud Detection Streamlit App

This project is a simple **Streamlit web app** for predicting the likelihood of fraudulent financial transactions using a machine learning model. It allows users to input transaction parameters and view prediction results interactively.

## 🚀 Features

- Two-page app interface:
  - **Project Description** with background and parameter list
  - **Model Prediction** with input fields and real-time prediction results
- Model trained using scikit-learn
- Inputs are preprocessed using `StandardScaler`
- Streamlit UI for interactive prediction
